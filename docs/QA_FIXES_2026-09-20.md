# DeepSpec QA and bug fixes — September 20, 2026

## Fixed in this batch

- Saving a cloud-only scan locally created a duplicate ID and discarded its
  inspection and notes. Save now retains the existing ID and human work.
- Retrying a failed cloud-only scan could restore the old failed result when
  saving or recording an inspection; reports could also show that old result.
  These paths now use the successful retry while preserving human evidence.
- Scanner cloud sync ran silently. A small status now distinguishes local-only,
  syncing, cloud saved, cloud failed, and failed local saves. Retrying cloud save
  does not spend another AI request. Completion from another scan cannot replace
  the current scan's status.
- Polar billing QA scripts decoded older raw webhook secrets as base64, unlike
  the supported API path. Synthetic signing/readiness tests now cover both raw
  and prefixed secrets. No payment or live billing webhook was sent.
- QA now classifies transport aborts/navigation timeouts as environment blockers,
  preserves the root authentication blocker for dependent flows, and gives the
  cloud service's 20-second timeout five extra seconds to render its final state.
  Missing save-state UI is a frontend finding, not evidence of a backend failure.
