# DeepSpec reliability session — September 30, 2026

Goal: prepare one supervised parts-seller trial by preserving saved work and making failures easier to investigate. This is engineering evidence, not a customer result or public-launch approval.

## Saved-record protection

The device reader previously returned an empty list when stored scans could not be read. A later scan, correction, inspection save or removal could therefore overwrite the original stored payload. A synthetic reproduction against baseline `e717bfb` confirmed byte loss for malformed JSON, a non-array value, a partly invalid list and a temporary read exception.

The reader now distinguishes empty from unreadable history. All nine record mutations refuse an unreadable store, leaving its original bytes unchanged. Cloud saves do not fall back to an old screen snapshot after a failed device read. New camera/upload analysis stops before an identification request when the existing store is unreadable.

Saved scans displays a recovery warning and a read-only retry button. A healthy later read restores the view without rewriting records. Available cloud records remain visible, with an explicit warning that they and their export may omit the newest unreadable device changes. The retry checks the mounted account so an old page cannot read another account's records.

This does not repair corrupted records, provide cross-device conflict resolution, or make browser storage a guaranteed backup. Preserve browser data if the warning persists. A single editing device/operator remains the trial constraint; second devices may check readback without editing concurrently.
