# Try DeepSpec without an account

Open `/demo` on the deployed app, or start `npm run dev` and open `http://localhost:5174/demo`.

Choose the brake-rotor or engine-bay sample, run the scan animation, open the authored review, try the follow-up prompts, and save/revisit the example. Saved sample IDs stay in this browser under the separate `deepspec.demo.saved-samples.v1` local-storage key. Reset demo clears only that key.

This route uses predetermined examples, not live AI analysis. It makes no account, identification, chat or billing API requests and does not start the camera or model prewarm. Sign in to analyze personal images with the normal app. The normal scanner, saved records and account routes continue to require verified authentication.

The UI uses the same static white vector identity and graphite surfaces as the normal app and landing page. Reduced motion keeps the photo still and softens the scan beam.
