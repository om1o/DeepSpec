# Art-direction reference assets

These three images are approved visual targets for the controlled hybrid documented in [`ART_DIRECTION.md`](../../ART_DIRECTION.md). They are preproduction references only and must not be imported as runtime textures or presented as screenshots of a working Unreal build.

- `direction-a-storm-authority-openai.png`: global exterior and grounded civic-infrastructure baseline.
- `direction-b-blackwater-pursuit-openai.png`: normal flooded-interior tension language.
- `direction-c-counterflow-cathedral-openai.png`: Bellman/finale scale reference only.

All three were generated with the built-in OpenAI image-generation workflow. The first two Higgsfield Z Image attempts for the full Storm Authority environment failed in the provider queue and charged zero credits, so they produced no asset. Higgsfield's successful contribution to this art direction is the separate floodlight concept and SAM 3D source recorded in [`higgsfield_floodlight_lineage.json`](../reports/higgsfield_floodlight_lineage.json).

The environment boards intentionally contain no reference-game logos, named characters, recognizable rooms, or copied creature designs. Exact prompts and SHA-256 hashes are recorded in `art_direction_lineage.json`.
